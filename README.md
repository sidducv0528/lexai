## 🎯 Project Vision

LexAI aims to be a lightweight, beginner-friendly NLP toolkit that helps users:
- 🏷️ Classify text into categories (positive/negative/neutral)
- 🔑 Extract keywords from documents and articles
- 📊 Analyse sentiment of customer reviews and feedback
- 📝 Summarise long-form text into concise outputs

## 🛠️ Tech Stack (Planned)

- **Python 3.x** — core language
- **NLTK / SpaCy** — NLP processing
- **Scikit-learn** — ML classification
- **TextBlob / VADER** — sentiment analysis
- **Streamlit** — interactive web interface
